# 🚗 Proton Saga Maintenance App

A lightweight web application designed to track, schedule, and log vehicle maintenance activities for the Proton Saga (VVT / Standard / Premium variants).

---

## 📌 Features

* **Service Logging:** Keep track of engine oil changes, transmission fluid (CVT/AT), spark plugs, and air filters.
* **Mileage Tracker:** Monitor mileage intervals and upcoming service reminders (e.g., 10k km, 20k km, 60k km major service).
* **Part Replacements:** Log wearable parts replacement such as brake pads, battery, wiper blades, and tires.
* **Cost Overview:** Track total spending on routine servicing and repairs.

---

## 🛠️ Tech Stack

* **Framework/Environment:** HTML / CSS / JavaScript (or React / Vite)
* **Deployment/IDE:** Built with Bolt.new & hosted on GitHub Pages
